בית משפחת קהא — גרסת Windows

- גרסה קלה: משתמשת ב־Microsoft WebView2 הקיים במערכת, ללא מנוע דפדפן נוסף בתוך המתקין.
- החלון והלוגו מופיעים מיד, והאתר נטען בתוכם.
- אשף התקנה ברור עם לוגו האתר ובחירת תיקיית ההתקנה.
- לוגו האתר על קובץ ההתקנה ועל קיצור הדרך בשולחן העבודה.
- פתיחה מוגדלת בהפעלה הראשונה.
- שמירת גודל החלון, מיקומו ומצב מסך מלא בין הפעלות.
- אותו אתר משפחתי, עם התוכן והעיצוב העדכניים.
- F11 למעבר למסך מלא ובחזרה. Alt מציג את תפריט האפליקציה.

The native host replaces the bundled Electron runtime. Microsoft's Evergreen WebView2 bootstrapper runs only if the shared runtime is missing. Existing window settings and the installation identity are retained. Website content updates automatically when the app connects.
